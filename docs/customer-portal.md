# حساب مشتری فعلی

مسیر `/account` و تجربهٔ فعلی ورود با موبایل، سفارش‌ها، پیگیری، آدرس‌ها، علاقه‌مندی‌ها،
گفت‌وگوی پشتیبانی، لغو/مرجوعی و نظر محصول حفظ شده‌اند. منابع حقیقت آدرس، علاقه‌مندی
و پیام از profile/گفت‌وگوی JSON جدا شده‌اند، اما شکل API برای پنل حفظ شده است.

سفارش فقط برای مالک تأییدشده نمایش داده می‌شود. افزودن سفارش مهمان نیاز به شمارهٔ
موبایل تأییدشدهٔ منطبق و کد دقیق سفارش دارد. session فقط hash توکن را نگه می‌دارد؛
cookie از نوع HttpOnly است. OTP خام در log یا صف ذخیره نمی‌شود و حالت development
در production غیرفعال است.

تصاویر پشتیبانی با اعتبارسنجی MIME، امضای محتوا و اندازه دریافت می‌شوند. bytes در
S3 خصوصی و مالک/هش/مشخصات در PostgreSQL هستند. API قبل از خواندن فایل، مالک یا
مدیر بودن را بررسی می‌کند. پاسخ خصوصی `Cache-Control: private, no-store` دارد.

ثبت سفارش دستی وضعیت پرداخت `unpaid` دارد. تأیید/ارسال با پرداخت یکی نیست.
لغو پیش از ارسال یک‌بار موجودی را آزاد می‌کند؛ تصویب مرجوعی به معنی استرداد وجه
نیست. اعلان پنل تراکنشی ثبت و پیامک فقط با تنظیم فروشگاه و رضایت مشتری توسط
worker ارسال می‌شود. شکست قابل retry است؛ provider بدون idempotency تضمین
ارسال دقیقاً یک‌باره ندارد.

برای فعال‌سازی واقعی و تنظیم SMS از [راهنمای عملیات](backend-operations.md)
استفاده کنید. نسخهٔ پیشین راهنما در `history/customer-portal-before-modular.md`
بایگانی شده است. حساب‌ها، پیامک و سرویس‌های محیط عملیاتی در این کار فعال نشده‌اند.
