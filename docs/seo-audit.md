# ممیزی اولیهٔ SEO ورسا

دامنهٔ بررسی شامل فروشگاه React، بسته‌های مشترک کاتالوگ و اعتبارسنجی، مسیرهای عمومی Express، تنظیمات Vite و Nginx و نمونه‌برداری خواندنی از دامنهٔ عمومی در ۱۷ نوامبر ۲۰۲۶ است. مبنای تغییرات پوشهٔ کاری است. Git محلی در آغاز فاقد commit و remote بود.

HTTP و میزبان `www` با ۳۰۱ به `https://varsasaffron.ir/` هدایت شدند. این مشاهده برای همان دو درخواست است. به تنظیمات فعال Nginx دسترسی مدیریتی استفاده نشد.

## تصمیم معماری

رندر React در زمان درخواست، با build جداگانهٔ Vite برای سرور و مرورگر و hydration همان رابط Wouter. Nginx دارایی ثابت و API فعلی را مدیریت می‌کند و درخواست صفحه و سند خزنده را به سرویس محلی فروشگاه می‌فرستد. این سرویس اطلاعات عمومی را با درخواست بدون کوکی به API می‌گیرد. مسیرهای خصوصی پوستهٔ فعلی را از همان سرویس دریافت می‌کنند.

رندر ایستا ساده‌تر اجرا می‌شود، اما همگام‌سازی قیمت، موجودی، دسته و وضعیت انتشار با بازسازی نیازمند چرخهٔ نشر دیگری است. SSR وابستگی زمان درخواست به API را می‌پذیرد و برای مسیر وابسته به داده در خرابی API پاسخ ۵۰۳ می‌دهد. تغییر کامل فریم‌ورک هزینهٔ بازآزمایی فروشگاه، سبد، پرداخت و پنل را بالا می‌برد. Wouter و React موجود از رندر سرور پشتیبانی می‌کنند.
