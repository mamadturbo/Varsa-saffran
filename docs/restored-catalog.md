# بازگردانی ۱۲ محصول اصلی — ۲۱ اکتبر ۲۰۲۶

به درخواست صریح مالک، فهرست هشت‌تایی جای خود را به ۱۲ بسته اصلی داده است: سوپر نگین، نگین، شبه نگین و پوشال؛ هرکدام یک گرم، دو گرم و یک مثقال. نام، وزن، قیمت و فایل بسته‌بندی با نسخه اولیه پروژه تطبیق داده شد. چهار بسته یک‌گرمی در محصولات منتخب خانه نمایش داده می‌شوند. محصولات سرگل، رشته و پک هدیه در فهرست فعال وجود ندارند.

منبع فعال مشترک فروشگاه، قیمت‌گذاری سفارش و متادیتا `lib/catalog/src/restored-products.ts` است. این انتخاب صریح منبع است و در پاسخ به قطع دیتابیس انجام نمی‌شود. تغییر آینده کاتالوگ به ویرایش همین فایل و build/deploy همزمان frontend و API نیاز دارد؛ ویرایش جدول Supabase فعلاً سایت را تغییر نمی‌دهد. reader قدیمی دیتابیس به‌عنوان ابزار مستقل و با تست‌هایش حفظ شده است. سه UUID مشترک با کاتالوگ قبلی حفظ شدند. سبدهای قدیمی با slugهای باقی‌مانده تطبیق می‌یابند؛ محصولات حذف‌شده سفارش تازه نمی‌سازند. بازپخش سفارش تاریخی تغییری نکرده است.

۱۲ PNG اصلی دست‌نخورده باقی ماندند؛ ۶۰ WebP با حفظ نسبت تصویر ساخته شد. فایل سوپر نگین دوگرمی کمی مستطیلی است و کامل نمایش داده می‌شود. Hero بازگردانده‌شده به نسخه قبل نیز حفظ شده است.

## وضعیت دیتابیس

درخواست نوشتن با دسترسی موجود توسط Supabase با HTTP 401 و کد 42501 رد شد. هیچ ردیفی در دیتابیس اصلی درج، ویرایش یا حذف نشده است. اصلاح فعلی سایت به این جدول وابسته نیست.

`restore-twelve-products.sql` برنامه انتقال همین ۱۲ ردیف به دیتابیس محصولات است؛ `restored-twelve-products.json` داده متناظر را دارد. اجرای SQL به اتصال دارای مجوز نوشتن نیاز دارد. SQL در یک تراکنش از جدول نسخه پشتیبان می‌گیرد، ردیف‌های ناشناخته را رد می‌کند، ۱۲ محصول را ثبت/به‌روز می‌کند و پنج slug قدیمیِ خارج از این مجموعه را حذف می‌کند. سفارش‌ها را تغییر نمی‌دهد. برای میزبانی زیرپوشه، مسیرهای تصویر ذخیره‌شده در SQL نسبت به ریشه سایت هستند؛ پیش از مصرف مستقیم جدول در سرویس دیگر، URL قابل دسترس تصاویر بررسی شود.

فایل‌های قدیمی `catalog-brand-images.sql` و `catalog-copy.sql` برای کاتالوگ هشت‌تایی قبلی تهیه شده بودند و برنامه بازگردانی فعلی نیستند. فعلاً آن‌ها را برای این بازگردانی اجرا نکنید.

## بررسی

۲۱۵ تست و build کامل موفق شد؛ تطابق هر ۱۲ نام/وزن/قیمت/تصویر با fixture مستقل اولیه، قیمت‌گذاری API با مبلغ دست‌کاری‌شده مرورگر، رد محصولات حذف‌شده، یکسانی منبع متادیتا و API، و migration روی PostgreSQL ایزوله بررسی شد. migration شامل پشتیبان هشت ردیف، اجرای دوباره و rollback در حضور محصول ناشناخته تست شد. این موفقیت، تأیید اجرای migration روی دیتابیس اصلی نیست.

در مرورگر توسعه، هر ۱۲ عنوان و تصویر متناظر، فیلتر سه‌تایی سوپر نگین و فیلتر یک‌مثقالی، جزئیات و JSON-LD با مبلغ صحیح و نبود صفحه/اسکیمای پک هدیه قدیمی بررسی شد. در پیش‌نمایش build روی پورت جداگانه، سوپر نگین دوگرمی با مبلغ ۸۴۹٬۰۰۰ تومان به سبد افزوده و سپس سبد آزمایشی خالی شد؛ سبد کاربر در پورت ۵۱۷۳ دست‌نخورده ماند. ثبت سفارش واقعی تست نشده است چون تنظیمات API و دیتابیس سفارش‌ها هنوز موجود نیست.
